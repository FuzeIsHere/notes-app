# 🚀 Recall
A full-stack personal knowledge management application with
GPU-accelerated semantic search and Firestore vector search.

- [Installation](#-installation)
- [Architecture](#-architecture)

## ✨ Features
- Rich-text notes with TipTap
- User authentication with Firebase
- Custom categories
- Pin, archive, trash and restore workflows
- Semantic search over notes
- Category and view-scope filtering
- GPU-accelerated embedding generation
- Asynchronous background embedding pipeline
- Multi-tenant data isolation
